# Third-party source

Strata is by the authors of [Niko1221/Strata](https://github.com/Niko1221/Strata), licensed under MIT. The port is based on revision `1678de333d0e0711bc414ad992b640e1a37dd814`. Its complete license is retained in `vendor/STRATA-LICENSE` and `LICENSE`. Equations and ordering were adapted from its CUDA kernels and `src/core/layer.cpp`. The unchanged files under `vendor/strata/` support the independent native oracle, canonical pack conversion/verification, and command-line tokenization. Browser inference arithmetic uses the port's compiled CUDA kernels.

CUDA WebShader is the user's [SamG-Coder/cuda-webshader](https://github.com/SamG-Coder/cuda-webshader) project, licensed under MIT, at revision `ef46ff1bf02a306bad94ddc18286d25d3d902c14`. The compiler, WebGPU runtime and experimental threaded WASM backend are vendored under `vendor/webcuda/`. The WASM CPU shim adds four CUDA bit-cast intrinsics using C++20 `std::bit_cast`; all other vendored WebCuda files remain unchanged. `PROVENANCE.json` records this modification and the file hashes. Its license is retained at `vendor/webcuda/LICENSE`. This project does not use Three.js for inference or presentation.

The deterministic fixture weights were generated for this project. They are untrained and contain no Qwen model weights. The application reads model/tokenizer files chosen by the user or served by its localhost server. It does not download them from a remote model hub. Each separately obtained model retains its own license; those weights are not included in this repository or in the fixture. Browser BPE and text-only Qwen formatting in `src/tokenizer.js` are adapted from Strata's tokenizer and the separately loaded model template; validation compares against the unchanged upstream Python and original Jinja template.

Playwright is a development-only dependency, pinned in `package-lock.json` and licensed under Apache-2.0. Emscripten/LLVM and a C++ compiler are external build/test tools; no SDK binaries are vendored.
